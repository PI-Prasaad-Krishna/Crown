Crown Browser Privacy Policy

Last updated November 19, 2026. Crown is built to stay on your device without telemetry servers, usage tracking, or account sync clouds.

Zero browser telemetry

Crown does not collect, log, transmit, or sell browsing history, search queries, shield counters, crash reports, or hardware identifiers. All Shield telemetry shown on the New Tab dashboard is stored solely on your local machine.

Local profiles and vault encryption

Each user profile keeps its own separate native OS WebView data directory (WebView2 on Windows) and profile storage keys so site sessions remain isolated. Credentials stored in the local vault are encrypted on disk with 256-bit AES-GCM and sealed with Windows DPAPI on Windows or owner-only 0o600 permissions on Unix.

Cookies, clearing data, and Incognito

Clearing browsing history, cookies, site data, or cache inside Crown invokes native WebView profile wiping (WebView2 ClearBrowsingData on Windows) directly against cookies, local storage, IndexedDB, service workers, and disk caches. Incognito windows open non-persistent private sessions that do not save history or custom shortcuts.

Optional network requests

Certain optional actions contact third-party hosts only when triggered by you: typing in the omnibox while search autocomplete is enabled queries your selected search provider, extension installs fetch packages from Chrome Web Store, and auto-update checks query GitHub Releases.

Promotional website notice

This website runs static HTML, CSS, and client-side JavaScript without third-party analytics trackers or ad scripts. Installer links point directly to official GitHub Releases.
