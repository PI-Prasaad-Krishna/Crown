Native request interception

Every outbound subresource is checked inside Rust before hitting the wire, while tracking query tokens strip cleanly.

Blocked at WebResourceRequested (Ad Shim Served)
Response: 200 application/javascript (window.google_ad_status = 1;) with zero external connection opened.

Separated sessions per profile

Each Crown profile mounts an isolated Chromium data folder and encrypted vault file, keeping cookies and accounts strictly apart.

web_profiles/default + Crown/vault.enc
Cookies, IndexedDB, LocalStorage, and Vault storage paths are partitioned inside web_profiles/default.

Three-tier tab hibernation

Background tabs release their child WebView2 process while preserving pinned order and full navigation history stacks.

Balanced: 2 active tabs, remaining tabs hibernated
Active and most recent background tab stay warm; inactive tabs unload child webview handles until focused.

Built to stay light under real tabs.

Instead of shipping a separate multi-hundred-megabyte browser runtime, Crown delegates rendering to your operating system WebView while Rust handles security boundaries.

Encrypted Local Vault
Saved site credentials are encrypted on disk with 256-bit AES-GCM, authenticated context data, memory zeroization, Windows DPAPI master-key sealing, and Unix 0o600 owner-only key isolation.
True Browsing Data Wipe
Clearing history, cookies, or site data triggers native WebView profile wiping (WebView2 ClearBrowsingData on Windows) across HTTP cookies, DOM storage, IndexedDB, and caches.
SSRF and Port Firewall
Direct fetches and file downloads verify DNS answers with short TTLs and inspect post-connect remote sockets to block loopback, cloud metadata, and private IPv6 tunnels.
Incognito and Split View
Dedicated private windows run non-persistent storage, while dual side-by-side Split View lets you browse two pages cleanly inside one workspace.

Isolated private windows use non-persistent RAM sessions and drop zero history keys to disk.

Clean workspace chrome with customizable shortcuts, top or left sidebar tabs, and offline QR sharing.
